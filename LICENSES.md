# Лицензии и происхождение

Это инвентаризация исходников, не заключение о лицензировании всей закрытой
сборки Level X. Полный file-by-file аудит её baseline ещё не выполнен.

| Компонент | Условия/происхождение | В поставке |
|---|---|---|
| Новый standalone C, тесты, tools, документы, MetalProbe | MIT, `LICENSE` | Исходники |
| Изменения `apple_displaypipe_v4.c` | Existing header AGPL-3.0-or-later, авторские уведомления сохранены | Patch hunks, без присвоения авторства upstream |
| Inferno в целом | Upstream LICENSE заявляет GPLv3 + собственные AGPLv3 части и отдельно оговаривает различные per-file licenses | Только notices и минимальный patch context |
| QEMU | Различные GPL/LGPL/per-file условия | Notices, без полного дерева/бинарников |
| Другие fork, reims-vgpu, XNU | Исследованы pinned источники | Код не заимствован; хеши/ссылки |
| Apple OS/firmware/SDK | Не включены | Нет |
| ChefKiss artwork/branding | Отдельные ограничения upstream | Только текст notice, artwork не включён |

В `licenses/` сохранены исходные COPYING, COPYING.LIB, GPLv3, AGPLv3,
LICENSE и CKBrandingNotice из точного baseline. MIT-модуль можно интегрировать
с сохранением его уведомления; это не отменяет условий окружающей производной
GPL/AGPL программы. При распространении либо сетевом использовании учитывайте
применимые требования соответствующих лицензий к исходникам и уведомлениям.

Upstream сам отмечает наличие исторических GPLv2-only частей. Нельзя объявлять
полную юридическую совместимость всей сборки по одному README: перед её
распространением нужна проверка конкретно связанных файлов и их условий.
Закрытый исходный Level X в этой сессии не был доступен.

Branding notice требует удаления защищённого artwork и названия из производных
сборок. Этот репозиторий распространяет source module/patches и не содержит
производный EXE с таким artwork. Патч не выдаётся за официальную сборку Inferno.
