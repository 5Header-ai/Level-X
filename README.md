# Level X

Независимая разработка графических компонентов для Level X Inferno / T8030.

Работа ведётся в ветке `feature/levelx-gpu` и передаётся основной команде через review и отдельные патчи. Полноценная модель A13 GPU и совместимость Metal пока не реализованы и не заявляются.

В ветке разработки находятся исходники, тесты, исследование готовых технологий, инструкции интеграции и фактические отчёты проверок. Apple firmware, диски, ключи и бинарные сборки в репозитории не распространяются.
