# ADR 0001 — проверенные интерфейсы до renderer

Принято 2026-10-14 для предварительного baseline.

Не создавать «Apple GPU» из виртуального FIFO с выдуманными opcodes. В просмотренном
T8030 пути есть display DMA, но нет доказанного AGX initialization/submission ABI.
Добавление Vulkan сейчас не обеспечило бы совместимость гостевого драйвера.

Первый компонент — bounded DMA/scanout с отключаемым адаптером к существующей
модели. Он полезен самостоятельно и не навязывает будущему AGX frontend его ABI.
Следующая аппаратная реализация допускается после документирования конкретного
контракта и негативных тестов. Независимые software операции используются как
эталон, а не как свидетельство Metal.

Цена решения: нет ускорения, дополнительная копия/аллокация на кадр, ограничения
размеров, сохраняются известные ограничения upstream compositor. Преимущество:
малый patch scope, отсутствие изменений общих QEMU/USB/SEP компонентов, простой
откат и воспроизводимые C-тесты. Блокеры не скрываются за API-success stubs.
